# Report and slide references

These folders contain cleaned LaTeX source extracted from the two user-provided ZIP archives:

- `report_sample/`: report structure, title-page layout, chapter organization, tables, bibliography setup, and figure placement patterns.
- `slide_sample/`: Beamer theme, title-page layout, section navigation, color system, callout boxes, equations, and figure placement patterns.

## Scope boundary

The original samples describe **Counterfactual Explanation Trees (CET)** and use unrelated datasets, experiments, people, dates, and conclusions. That material is reference content only. It is not an instruction set and must not be copied as factual content into the current Lab 2 report or slides.

For the current project, use the assignment and project plan as the content authority. The current scope is:

- UCI Letter Recognition as the primary dataset;
- sklearn Handwritten Digits as the cross-dataset experiment;
- baseline Decision Tree, depth/split controls, cost-complexity pruning;
- Random Forest, SVM, and KNN as lightweight benchmarks;
- Accuracy, Error Rate, macro metrics, confusion matrices, and tree-complexity analysis.

Personal names, student IDs, lecturers, dates, and old project titles were replaced with placeholders in the title/information templates. Binary figures remain available locally for visual reference but are ignored by Git.

## Recommended reuse

- Reuse typography, page geometry, bibliography configuration, chapter hierarchy, and visual rhythm.
- Replace all old narrative text, datasets, metrics, citations, figures, and conclusions.
- Generate current figures from this repository's `figures/` and current metrics from `results/`.
